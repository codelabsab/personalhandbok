# Sjukfrånvaro

Vid sjukdom eller vård av barn är det viktigt att du meddelar detta till kunden, din närmaste chef och rapporterar i[Excel Tidrapportering  ](https://docs.google.com/spreadsheets/d/1tivwCccIZ0pI3542zr-LqSijQFHnPyZIpk1uDAXqE8c/edit?gid=154123441#gid=154123441)Det behöver göras redan dag 1 vid sjukdom. Det går bra att göra sjukanmälan via telefon (08-128 164 00) eller mail till Code Labs: contact@codelabs.se

Om du inte kan arbeta av annan anledning, hör av dig till närmaste chef.
