# Hälso- och friskvård

Code Labs värnar om medarbetarnas hälsa och erbjuder därför alla anställda ett friskvårdsbidrag på upp till 5 000 kr per år. Friskvårdsbidraget kan användas för att bekosta aktiviteter som främjar fysisk och psykisk hälsa, till exempel medlemskap på gym, simning, yoga eller gruppträning.

# Rikskort

Code Labs erbjuder ett förmånskort som syftar till att subventionera medarbetares matkostnader. Förmånen tillhandahålls i form av ett kort som laddas med ett fast belopp varje månad. Kortet skickas hem till medarbetaren och kan även användas digitalt, exempelvis via Apple Pay.

Förmånskortet kan användas som betalkort hos anslutna restauranger och butiker, som går att hitta via deras app.

Kortet laddas med 2 900 kronor per månad, vanligtvis omkring den 25:e. Av detta belopp görs ett löneavdrag motsvarande 30 procent, vilket innebär att resterande del utgör en subvention från Code Labs.
